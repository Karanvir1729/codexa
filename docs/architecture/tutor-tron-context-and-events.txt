Typed event contracts:

- transcript.final
- student_state.updated
- pitfall.detected
- cohort.strategy.recommendation
- candidate_actions.generated
- scip.action_selected
- strategy.failed
- strategy.succeeded
- eval_case.generated
- strategy.promoted
- strategy.rollback
- latency.spike

Each event should include:

- event_id
- session_id
- student_id
- timestamp
- source_service
- schema_version
- idempotency_key
- payload
